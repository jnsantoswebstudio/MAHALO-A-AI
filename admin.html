Publicação no GitHub Pages

  1. Baixe o site-data.js atualizado.
  2. Abra seu repositório no GitHub e selecione o arquivo site-data.js.
  3. Use Upload files para substituir o arquivo, ou faça commit pelo computador.
  4. Aguarde a execução do GitHub Pages. Atualize o site público para ver a nova versão.

Importante: nunca coloque tokens, senhas ou credenciais do GitHub no arquivo do site ou neste painel. Administração protegida com publicação direta exigirá backend e autenticação reais.
